# ai-study-assistant
AI-powered study assistant that generates quizzes, flashcards, and step-by-step explanations to make learning smarter.


An AI-powered productivity app that helps users manage tasks smarter by generating subtasks, tracking progress, and suggesting priorities.

---

## 🚀 Live Demo
👉 [Try the App Here](https://ai-smart-to-do-list.ai.studio)

---

## ✨ Features
- Add tasks with ease
- AI-generated subtasks for smarter planning
- Progress tracking with checkboxes
- Simple and clean web interface
- SQLite database for task storage
- Deployable on cloud platforms (Heroku/Render/Azure)

---

## 🛠️ Tech Stack
- **Frontend:** HTML, CSS
- **Backend:** Flask (Python)
- **Database:** SQLite
- **AI Models:** Hugging Face / OpenAI API
- **Deployment:** Docker + Cloud Hosting
